[3.5.0.11] - 11 Sep, 2026

- Changed: Raise the minimum PHP version to 7.4. The autoloader generated by Strauss 0.29 enforces it via `lib/composer/platform_check.php`, even though upstream Pimple still allows 7.2.5
- Changed: Upgrade Strauss to 0.29.2 and regenerate the prefixed library. Live classes moved to `lib/pimple/pimple/src/PublishPress/Pimple/`, and the runtime autoloader is now `lib/composer/` instead of `lib/autoload-classmap.php`
- Changed: Rename the newest-wins loader from `Versions` to `VersionLoader`, keeping `Versions` as a class alias for older consumers
- Changed: Move the Codeception suites to `tests/codeception/` with `.env` / `WP_TESTS_*` params, replacing the `wpunit` suite and `.env.testing`
- Fixed: Strip the nested `PublishPress\Psr\Container` copy from the `lib/composer/` autoload maps after Strauss 0.29, so PSR-11 types come from `publishpress/psr-container` instead of a second bundled copy
